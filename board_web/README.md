# V1.0 棋盘前端

由 Python 主程序加载，先选择班级再进入内置棋盘。不要直接打开 index.html；运行和构建步骤见根目录 README。

- app.js：拖动、缩放、投骰、逐格移动、揭晓、宝箱合盖和同步。
- scene.js：实体棋盘、国王棋子和嘉年华布景。
- dice.js：以顶面表示点数的实体倒角骰子。
- console.js：规则、VIP、名单、宝箱和展示设置。
- probability.js：概率配平与随机分配。
- board-model.js：路线坐标及模型测试辅助函数，实际点名使用 Python 规则。
- assets/starfield.png：内置星空背景。
- vendor/：Three.js 0.160.1 及 MIT 许可。

默认示例为50个姓名格和10个宝箱格。每颗骰子1～6步，从当前位置向前走；普通学生结果限定在可达格中，宝箱随机学生沿用原抽取规则。VIP必抽可由宝箱完成，直接到VIP姓名格也计为完成。

四项展示设置可任意组合，各项时间0.1～60秒；无音效。双击棋盘跳过本批剩余展示并保留结果。

前端测试使用模拟 DOM/渲染器或实际模型投影，不代表人工视觉验收。主程序 --window-health-check 提供实际窗口自检。
