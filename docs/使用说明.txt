班级随机点名器 V1.0 使用说明
========================================
版本日期：2026年9月28日

一、启动与首次使用
1. 完整解压压缩包到可读写文件夹，双击“班级随机点名器_V1.0.exe”。不要直接在压缩包内运行。
2. 先进入开始界面，选择班级后进入3D棋盘。
3. 发布包不携带旧测试版数据。首次启动会生成50人的示例班级，其中包含示例VIP。正式使用前请新建班级、录入实际名单，并核对VIP设置。
4. 正常使用无需联网，星空背景、棋盘与骰子资源均已内置，不必另放背景图片。
5. 本程序为Windows 64位版本。3D窗口需要本机具备Microsoft Edge WebView2运行时，缺少时请先安装该组件。

二、棋盘操作
按住棋盘空白处拖动：上下左右移动视图。
滚轮或右上角“＋ / －”：缩放。
“棋盘总览”：查看整体路线。“定位棋子”：找到国王棋子。
右上角全屏按钮：进入/退出全屏；棋盘获得键盘焦点时也可按F11。
右侧“本轮已点名”保留本轮结果，底部“点名记录”可查看历史。

三、掷骰与落格
1. 右下角“－ / ＋”设置骰子数量，表示本批计划点名人数，点击“掷骰”开始。没有消耗骰子的确认弹窗。
2. 每颗骰子点数为1～6，棋子从当前位置向前走对应格数；不会为追到远处目标而自动追加投掷。
3. 普通姓名格的抽取范围是前方1～6格内符合条件的学生，不能一次直接点到棋盘任意位置。
4. 投骰、落格后揭晓结果。停在姓名格点名该学生，停在宝箱格执行事件。
5. 宝箱可能是提示或跳过等非学生事件，因此实际点名人数可能少于计划人数，以结果区和右侧名单为准。
6. 每位学生一个姓名格，同名学生用编号等信息区分。导入时建议为同名学生设置不同编号。
7. 同一轮布局保持固定；刷新轮次或调整参与名单后，学生与宝箱布局会相应更新。
8. 没有合格的可达学生时，按规则处理宝箱或提示不能继续，骰子不会超过6点。

四、双击跳过
投掷开始后，双击棋盘可跳过本批剩余展示并回到待投掷状态。
跳过不会重新抽取、撤销已产生结果或改变本批最终落格，也不改变下批的动画设置。

五、显示与动画（无音效）
点击掷骰区域常驻的“显示与动画”，或进入控制台的显示设置。
四项可分别勾选，可全选、全不选或仅选一项：
“直接显示”：静态结果卡显示姓名或事件。
“骰子动画”：屏幕中央显示投掷，以骰子顶面点数和数字提示为准。
“移动动画”：棋子逐格移动。
“名字凸显”：屏幕中央大字显示姓名或事件。
每项时间可独立设置为0.1～60秒，保存后生效。骰子、移动时间按每颗骰子计算；移动时间是该次全部步数的总时长。
全不勾选时快速完成展示，结果仍保留在结果区和本轮名单中。

六、控制台与同步
“控制台”集中提供规则、宝箱、名单、显示等设置。修改后点击对应保存按钮；VIP和移出/恢复等直接操作会立即应用。
完整管理界面保存修改后，返回3D棋盘会自动更新，不需要手动同步。
控制台“更多”中的“打开完整管理界面”可进入Excel导入导出、临时缺席、补抽和数据维护等功能。

七、规则、轮次与VIP
普通、不重复、均衡等规则沿用原点名器：普通按合格范围随机，不重复排除本轮已点名学生，均衡使用学生当前权重。3D普通落格仍受前方1～6格限制。
“刷新轮次”开启新一轮，并重新安排学生和宝箱位置；历史记录仍可查看。
VIP是用户设置的必定抽取项，结合VIP开关、每批VIP人数和待完成状态使用。需要安排VIP结果时通过宝箱事件完成；直接落在VIP学生的姓名格并点到该学生，也算完成该VIP。
VIP不足时是否用普通学生补齐，由对应开关控制。补齐不会改变普通学生身份；无法满足设置时请按提示调整人数或规则。

八、宝箱内容与概率
在宝箱设置中可增删事件、修改内容、选择类型和调整概率。
事件包括自定义提示、幸运跳过、老师指定、再掷一次、随机学生。
“随机学生”从当前合格学生中按原有规则和权重选择，不局限于棋子前方六格，遵守缺席、移出、不重复和VIP规则。没有合格学生时不会产生学生结果。
“老师指定”和“再掷一次”需通过“处理宝箱事件”继续，不会擅自追加骰子。宝箱展示后自动合上。

两种概率：
“抽到宝箱格的概率”控制普通投掷落入宝箱的倾向，仍受当前位置、可达格子和合格名单限制；VIP必抽有独立优先规则，不能理解为所有情况下的最终统计占比。
“宝箱内容概率”决定普通宝箱内各事件的概率，总和需为100%。

智能调整：修改一项时，其余项优先按原比例分配剩余概率，总和保持100%；其余项全为0时平均分配剩余值，只有一项时为100%。
关闭智能调整后可手动修改各项，仍须总和100%再保存。
“调整至随机概率”生成一组总和100%的随机比例，核对后保存。

九、名单管理
“名单与VIP”可搜索、改名、设置VIP、移出/恢复。
改名后点击“保存姓名”，沿用该学生原身份、历史和VIP设置。
“移出”暂停参与并保留记录，“恢复”重新在册。
批量导入请进入完整管理界面的名单管理。使用.xlsx文件，第一张表A列姓名、B列编号，参考随包的“样例名单_仅供测试.xlsx”。正式导入请换成实际名单。
导入前核对预览、导入方式及重复提示。同名学生建议使用不同编号，相同编号对应不同姓名会冲突；旧.xls请先另存为.xlsx。
也可通过管理界面粘贴录入、手动新增或导出名单。

十、临时缺席与补抽
临时不在场的学生可设置缺席截止时间或手动恢复，缺席期间暂停参与抽取。
对最新一批结果设置缺席时，界面会说明是否使其失效并产生补抽缺额，请确认后执行。
通过完整管理界面的对应入口补抽，沿用该批相关规则；历史可查看日期、批次和结果状态。

十一、数据、备份与迁移
默认保存在EXE所在文件夹的data目录，首次运行自动创建。
主要文件为data_python.json，.bak为保存备份，backups目录保留维护操作生成的完整备份。
不要运行中手动删除、编辑或覆盖数据。U盘使用完请先关闭程序再拔出。
使用默认位置时，迁移请连同程序和data目录一起复制。
设置了自定义保存位置后，数据仍在所选目录；移动EXE不会改变该位置，程序旁storage_config.json记录位置配置。
请通过“更改保存位置…”迁移，选择安全的空文件夹；程序会复制校验，并保留原目录。
本程序不提供云同步，不上传班级名单。3D界面与主程序仅在本机通信。

十二、保护密码、重置和恢复
初始保护密码：admin。可在本地数据保护区域修改，请妥善保存。
“一键重置”可选择范围和内容，清名单会连带清历史、进度，清历史会连带清进度，执行前请核对影响。
清除前必须成功备份；备份失败不会继续清除。
“恢复本地备份”会以所选备份替换当前数据，并先备份当前状态。
注意：“忘记密码”会先备份，再清空当前全部班级数据并恢复初始密码，并非只修改密码。需要取回数据时，再使用“恢复本地备份”。

十三、常见问题
“访问无效 / 请从主程序打开”：请从EXE启动并选班级，不要单独打开网页文件或复用旧页面地址。
3D窗口无法启动：检查WebView2运行时、显卡驱动及文件夹写入权限，关闭后重启。
名字显示太快：勾选直接显示或名字凸显、增加对应时间；也可查看右侧本轮名单。
人数少于计划：检查非学生宝箱事件，以及缺席、移出、VIP和不重复设置。
旧测试数据未出现：本发布包独立使用示例数据。若要迁移，先备份，再通过名单导入或正确的保存位置操作，不要直接覆盖唯一原数据。

十四、发布包内容
班级随机点名器_V1.0.exe：内置星空背景及3D资源的主程序。
使用说明.txt：本说明。
样例名单_仅供测试.xlsx：导入格式参考。

推荐流程：解压 → 启动 → 新建/选择班级 → 导入并核对名单 → 设置规则与VIP → 设置宝箱和展示时间 → 掷骰点名。
